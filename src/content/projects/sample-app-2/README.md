# TL;DR

This project deconstructs the "Black Box" nature of modern AI by building Neural Networks entirely from first principles. Instead of relying on high-level abstractions like PyTorch or TensorFlow, this repository implements the core mathematical engine using only **NumPy**. It bridges the gap between theoretical formulas and working code, offering a transparent view of how automatic differentiation, backpropagation, and computational graphs actually function under the hood.

# Key features

- **Matrix-Level Implementation:** Manual calculation of forward and backward passes (Backpropagation).
- **Custom Architecture:** Built-from-scratch Layers (Dense, Conv2D), Activations (ReLU, Softmax), and Optimizers (SGD, Adam).
- **Modular Design:** A flexible, object-oriented framework that mimics the structure of professional libraries.
